# Proxy

The undo layer for AI agents. Every agent will make mistakes in the real world. Proxy gives each task its own email address, captures every receipt and Stripe charge, compares them with the intent, traces everything one mistake broke, texts the human once, and undoes it all, agent to agent, before the refund window closes. It then confirms the money in Stripe and hands the corrected intent back to the original agent to redo it right. A scoreboard from real runs compares Proxy to an agent that checks its own work.

Hackathon: YC Make Something Agents Want. Tracks: Manufact and Inkbox. (The repo folder is still named `tripwire`.)
